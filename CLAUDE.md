# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

APEX is an algorithmic trading bot that runs a pure momentum strategy against gold (**XAUUSD** is the default instrument) on **Exness via MetaTrader 5**. The core engine (strategy, backtest, comms, ops) is **stdlib-only**; MetaTrader5 is required only for live data + execution and is **Windows-only** (it talks to a running, logged-in MT5 terminal — there is no headless/Linux mode).

Local checkout lives at `C:\Apex` on the operator's Windows machine.

## Commands

```bash
# Run the full test suite (132 tests, no network/MT5 needed — all I/O is mocked)
python3 -m pytest -q
python3 -m unittest discover -s tests        # equivalent, stdlib-only

# Run one test file / class / method
python3 -m pytest tests/test_strategy.py
python3 -m pytest tests/test_strategy.py::EvaluateTests::test_uptrend_generates_buy

# Install live-trading deps (Windows only; engine itself needs nothing)
pip install -r requirements.txt
```

### Operator workflow (run on Windows with MT5 terminal open + logged into Exness)

```bash
# 1. Pre-flight — ordered checks; exit 0 = ready. Also prints connected
#    account login/server/balance/equity from mt5.account_info().
python3 scripts/preflight.py XAUUSD --interval 4h

# 2. Re-tune on REAL gold data (mandatory before live — see "Config" below)
python3 scripts/tune.py --symbol XAUUSD --interval 4h --limit 2000 --mt5 --write

# 3. Dry-run (full loop, no real orders)
python3 scripts/live.py XAUUSD --interval 4h --dry-run

# 4. Go live
python3 scripts/live.py XAUUSD --interval 4h --lot 0.01
```

`scripts/fetch_ohlcv.py --list-symbols --mt5` lists the broker's exact symbol names. The data loader can also pull Binance OHLCV (stdlib `urllib`) or read a CSV, but **Exness/MT5 is the production path**.

## Architecture

Data flows **OHLCV bars → pure `evaluate()` → Signal → executor/gateway**, with an ops + comms layer wrapped around the live loop.

- **`apex/strategy/`** — the heart. `decision.evaluate(bars, StrategyConfig)` is **deterministic and side-effect-free** (no I/O, time, or state): it applies an ATR band filter → spread filter → momentum threshold and returns a `Signal(action, score, reason)`. `bars.py` has the pure `Bar` dataclass + `atr()` / `momentum_score()`. `config_loader.py` is a **stdlib-only two-level YAML parser** (no pyyaml) that builds `StrategyConfig` from `config/core.yaml`. Keep this package dependency-free and pure — it's what makes the engine fully testable offline.

- **`apex/execution/`** — `PaperGateway` simulates fills (slippage, fees, one position at a time) for **backtests**. Mirrors the live executor's one-position-at-a-time contract.

- **`apex/data/`** — `loader.load_bars()` routes to CSV / Binance / MT5 by argument. `mt5_loader.py` (read OHLCV) and `mt5_executor.py` (submit/close orders) are the **only** modules that import `MetaTrader5`, lazily, so the rest of the codebase imports cleanly on any OS. `MT5Executor` is also one-position-at-a-time and has `close_all()` for emergency flatten.

- **`apex/backtest/`** — `BacktestRunner` replays bars through `evaluate()` + `PaperGateway`; `WalkForwardValidator` does anchored/expanding-window out-of-sample validation. **`mean_oos_sharpe` is the anti-overfitting signal** — `scripts/tune.py` ranks candidate configs by it.

- **`apex/ops/`** — `CircuitBreaker` (pauses order submission after repeated failures), `Watchdog` (fires if the loop stalls), `ThrottledNotifier` (rate-limits phone alerts). Safety net around live execution.

- **`apex/comms/`** — provider-agnostic remote **notify** + **control** (`KILL`/`STOP`/`STATUS`) over ntfy. Everything sits behind a `Transport` seam (`InMemoryTransport` for tests, `NtfyTransport` for prod), so it's fully testable with no network. When `NTFY_ENABLED` is unset/false the agent is a no-op and the bot runs unchanged. See `apex/comms/README.md` and `docs/phase-5d-*.md`.

- **`scripts/live.py`** — wires it all together: loads config → `MT5Executor` → `CircuitBreaker` + `Watchdog` + `CommsAgent`/`ThrottledNotifier` → main loop (`load_from_mt5` → `evaluate` → submit if actionable & breaker closed → sleep aligned to the next bar boundary). SIGINT/SIGTERM and remote KILL/STOP all route through `_kill()` → `executor.close_all()`.

## Config (`config/core.yaml`)

Auto-generated by `scripts/tune.py --write`. **Important:** the committed values are gold-*scaled* but produced from **synthetic** data, not real XAUUSD — they are a placeholder. `tune.py` derives the filter grid from the data's own percentile distribution (spread/ATR/momentum), so bands are instrument-specific. **Re-tune on real XAUUSD data before trusting live signals.** BTC-tuned bands are wrong for gold (gold's volatility and spread are structurally much lower).

## Constraints & gotchas

- **MetaTrader5 is Windows-only and needs a live terminal** — anything touching `mt5_loader`/`mt5_executor`/`scripts/live.py`/`scripts/preflight.py` against real data must run on the operator's Windows box, not in CI or a Linux sandbox.
- **XAUUSD is not 24/7** — gold has market hours; expect data gaps on weekends.
- **Lot sizing:** `--lot 0.01` for XAUUSD ≈ 1 oz ≈ ~$240 notional. Confirm before raising.
- Keep `apex/strategy/` pure and stdlib-only; isolate all MT5 imports to `apex/data/`. This is what keeps `python3 -m pytest` green with zero external dependencies.
